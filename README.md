# auto-QEC-CSS-codes
The Qiskit framework presented here is for automating the circuit generation for the detection (sydrome extraction) and error correction circuits for any single Pauli error for a class of quantum error correction codes called CSS (Calderbank-Shor-Steane) codes. The only input parameters needed are an encoding circuit and the number of qubits in the encoding circuit. Test encoding circuits for bit-flip, Steane, and Shor codes are also available. The master document is a Jupyter file intended to walk through how to use the circuit generation algorithm for those who may be unfamiliar with quantum error correction. This framework was created with the hope that researchers, regardless of experience level, can use it to easily test their hardware under error correction. Future work could include expanding the code beyond single errors and logical qubits, as well as integrating different classes of QEC codes into the automation logic.

This framework was developed as part of a research effort conducted at Western Illinois University under the advisement of Kishor T. Kapale, with the bulk of the code developed by Chelsie Hadley (this author) and significant contributions from Pradip Bhattarai (Southern Illinois University, Carbondale) and Al-Maliq Adetunji (University of Maryland, Baltimore County)
